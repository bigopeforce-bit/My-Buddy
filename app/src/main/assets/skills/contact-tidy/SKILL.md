# Contact tidy

Use when the user asks to clean up their contacts, find duplicates, or who they have lost touch with.

1. Read the contacts list as it is. Do not change anything while reading.
2. Group what needs attention: the same person twice (same name, different entry), entries with no number, entries
   with no name, and numbers that look wrong (too short, too long, or the same digits twice).
3. For each duplicate, say which two entries it is and what would be kept, so the user can choose.
4. Offer a work list first: what would be merged, what would be filled in, what would be archived.

## Rules
- Never delete or merge a contact without the user naming that contact.
- Never guess which number is the right one when there are two; ask.
- Do not send a message to a contact as a test.
