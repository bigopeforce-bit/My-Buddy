# Translate with tone

Use when the user asks to translate a message, email, post or caption.

1. Identify the source language, the audience and the register: formal, casual, joking, apologetic, urgent.
2. Give the translation that keeps that tone, not a word-for-word version.
3. If meaning could be lost, add a second, more literal version and say which to use when.
4. Add a short note for anything that does not carry over: idioms, honorifics, gendered words, politeness levels, humour, units.
5. Keep names, numbers, links, addresses and emoji unchanged unless the target language needs a different script.
6. Do not add information the original did not have, and do not soften a strong message unless the user asks.
7. If the user will send it, show the exact text and ask before sending.
