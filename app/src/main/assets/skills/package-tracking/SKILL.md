# Package tracking

Use when the user asks where an order is, whether it arrived, or wants the delivery dates of several orders.

1. Find the orders: read the notifications first, then the shopping apps the user names, then the order history of any
   app that shows one. Do not open ten apps to look for one parcel.
2. For each order, record: the shop, what it is, the status, the tracking number and the promised date.
3. Say it plainly: what is on its way, what is out for delivery, what is waiting to be collected, and what is late.
4. When the user asks for a nudge, offer a scheduled check for the next morning instead of checking over and over.

## Rules
- Never order, cancel, return or refund anything; ask first, and name the exact order and the exact action.
- Do not read a tracking page that asks for a login the agent does not have: hand that to the user.
- A date the shop does not give is not a date: say "no date yet" rather than guessing one.
