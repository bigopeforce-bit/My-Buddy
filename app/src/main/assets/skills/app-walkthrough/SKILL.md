# App walkthrough

Use when the user asks "show me how", "where is this setting?", or wants to learn a step in an app.

1. Ask what they want to end up with, then open the app.
2. Read the screen. Point out one thing at a time with a short label, and wait for the user to do it.
3. After each step, read the screen again. If the app moved somewhere unexpected, adapt instead of repeating the old step.
4. Keep labels short and concrete: "Tap here", "Your email", "Then Save".
5. Do not tap for them unless they ask you to. Never type passwords, one-time codes or payment details.
6. At the end, summarise the steps in one short list so they can do it again alone.
7. If a permission or login screen appears, stop and explain what it wants before going on.
