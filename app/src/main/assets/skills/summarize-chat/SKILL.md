# Summarize a chat

Use when the user asks "summarize this chat", "catch me up", or shares a long conversation.

1. Read enough history to cover the whole topic. If the conversation is long, scroll to where it starts instead of reading only the last screen.
2. Output, in this order:
   - **TL;DR**: three lines at most.
   - **Decisions**: what was agreed, by whom.
   - **Action items**: who does what, and by when. Mark missing owners or dates.
   - **Open questions**: what is still unresolved.
   - **Links and files**: anything shared that matters, with who sent it.
3. Keep names exactly as shown. Never attribute a quote to the wrong person.
4. If two people disagree, say both positions in one line each.
5. Do not reply, react or forward anything.
