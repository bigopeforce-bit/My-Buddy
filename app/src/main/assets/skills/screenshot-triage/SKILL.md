# Screenshot triage

Use when the user sends a picture of a screen (a chat, an order, an error, a receipt) and asks what it is or what to do.

1. Read the picture carefully: the app, the screen, what is selected, and every number and name that matters.
2. Answer in plain words what the screen shows and what the user probably wants. One short paragraph, then the facts.
3. If the next step is obvious (a button, a reply, an order to open), offer it as a single sentence the user can approve.
4. If the user says go ahead, open that app and carry on from there, using the screen as it is now.

## Rules
- Say when something is unreadable or cut off, instead of guessing a number or a name.
- Do not tap, send or buy anything while reading the picture; only when the user says so.
- Keep a picture's personal details (addresses, card digits) out of the reply unless they are asked for.
