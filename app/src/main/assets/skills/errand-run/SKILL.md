# Errand run

Use when the user asks for a batch of small things on the phone at once.

1. List the errands first, in the order they can be done, and check which apps they need. Say the plan in one line.
2. Do them one after the other, reading each screen before acting. Stop at the first thing that needs the user.
3. Keep a short note of every result as you go: the answer, not the steps.
4. Report at the end: one line per errand, with what came back, then anything that needs a decision.

## Rules
- One thing at a time: do not leave an app half-done to start the next errand.
- Anything sent, bought, posted or deleted waits for the user's OK, even mid-run.
- If an errand turns out to be a bigger job than it looked, finish the small ones first and say what is left.
