# Travel kit

Use when the user has a trip coming and wants the preparation handled.

1. Work out what the trip needs: the date, the place, how long, the transport and who is going.
2. **Documents**: list what has to be with them (passport, visa, tickets, insurance, cards) and what to check on each.
3. **Packing**: a list by bag and by day, short enough to tick off, with the things that are easy to forget.
4. **On the phone**: set the alarms (check-in, departure), put the addresses in the maps app, and check that the
   tickets are where they can be opened offline.
5. Offer a short check the evening before, as a scheduled task.

## Rules
- Never book or pay for travel; ask first, with the exact price and time.
- Never write a passport number, a card number or a code into a note or a message.
- Say when a document's deadline is close (visas, passport validity) rather than assuming it is fine.
