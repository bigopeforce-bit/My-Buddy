# Reply like me

Use when the user says "reply for me", "write it like I would", or asks for a draft in their voice.

1. Read the last 20 or so messages the user sent in this conversation, plus the message being answered.
2. Note the style before writing:
   - language and formality, greetings and sign-offs
   - typical sentence length: short lines, or full paragraphs?
   - emoji, punctuation, slang, capitalisation
   - how they say no, apologise or ask for something
3. Draft two options: one short, one slightly warmer. Both must sound like the same person.
4. Keep every fact from the conversation. Do not add promises, times or prices the user did not give.
5. Show the drafts as quotes with a one-line note on the tone. Send only after the user picks one and approves the exact text.
6. If the conversation is sensitive (money, health, a conflict), say what the draft assumes and offer a more cautious version.
