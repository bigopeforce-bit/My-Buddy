# Daily brief

Use when the user asks for a morning brief, a daily summary, or "what did I miss?".

## Gather, only what is available
1. Read the phone's notifications and group them by app and by person.
2. Read the calendar for today and tomorrow.
3. Open the two or three conversations that look urgent. Do not open everything.

## Write the brief
- Start with **Do now**: at most three things that need the user today, each with one line of context.
- **Today**: meetings and deadlines in time order, with the next one first.
- **Waiting on you**: messages from people who asked a direct question. Name the person, not the app.
- **Can wait**: one line for everything else, no list.
- End with one suggestion for the first thing to do, if it is obvious.

## Rules
- Never invent a meeting, message or deadline. If something is unclear, say so.
- Do not reply, RSVP or tap anything while writing the brief.
- Keep it under 150 words unless the user asks for detail.
