# Receipt tracker

Use when the user shares receipt photos, asks for expense totals, or wants a spending table.

1. Read each receipt one at a time. Extract: date, vendor, total, currency, tax, payment method if shown, and a short category.
2. Make one row per receipt. Keep the currency as printed; do not convert unless the user asks.
3. If a total or date is unreadable, mark it "unclear" and ask for a clearer photo. Never guess an amount.
4. After the table, give:
   - count and total per category
   - the overall total
   - duplicates: same vendor, same date, same amount
5. Ask before saving a CSV. When asked, save it in the work folder and say where it is.
6. Do not photograph, open or use banking apps for this. Receipts only.
